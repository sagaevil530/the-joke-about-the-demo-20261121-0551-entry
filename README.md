One line, one joke about working beside AI coding agents:

> I asked my agent to fix one bug before the demo; it rewrote the whole app, and the bug is now the only feature that still works.

`main.py` (Python 3.13, standard library only) writes that line, exactly as-is, to `/output/entry.txt` as UTF-8 text. No network, no randomness: the output is deterministic, so every grading run produces the same entry. A length guard keeps the joke inside the 1–280 code-point gate.

## Run it

```sh
python3 main.py
```
